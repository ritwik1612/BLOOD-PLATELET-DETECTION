## BPD 2.3.0

Updated Windows desktop interface:

- Black background, blood-red accents, and bundled offline fonts.
- Direct upload and results workflow with original-image and detection views.
- Muted green normal-reference boxes and red review-candidate boxes.
- A morphology-score chart with each cell's score relative to its existing threshold.
- Click red boxes to highlight their graph points and show exact scores and thresholds.
- RBC, WBC, and platelet chart filters.

The detector, anomaly scoring, configuration, calibration, model weights, and existing backend API are unchanged. This release updates the interface, desktop presentation bridge, and installer.

Download **BPD-Setup-2.3.0.exe** below. Setup updates an existing BPD installation and keeps the BPD Start menu / Windows Search entry. The app performs local CPU inference and does not require a terminal or a browser server.

Source code is available in this repository and the automatically generated source archives. Training datasets and research documents are not included.
