# BPD V2 App
Windows installer for BPD V2 local blood-smear analysis.
## Install
Download `BPD-V2-App-Setup-2.0.0.exe` from Releases, run it, choose an installation folder, and select **Launch Blood, in focus.** when setup completes. The app is also available in Windows Search as **BPD V2 App**.
The release contains only the installer: no datasets, source code, notebooks, or experimental artifacts.
Research-use software. Morphological candidate flags are not a diagnosis.
