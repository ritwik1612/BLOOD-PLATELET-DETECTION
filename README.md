# BPD V2 App

Windows installer for the BPD V2 local blood-smear analysis application.

## Download and install

Download `BPD-V2-App-Setup-2.0.0.exe` from the latest release, run it, choose an installation folder, and select **Launch Blood, in focus.** when setup completes. The installer adds **BPD V2 App** to the Windows Start menu, so it can also be opened from Windows Search.

The application performs local inference with a YOLOv8n detector and convolutional-autoencoder morphology scorer. It accepts PNG and JPEG smear images up to 20 MB.

## Package contents

The release contains the installer only. It does not include training datasets, notebooks, development source, experimental weights, or prior evaluation output.
